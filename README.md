# ChemVerse · 化学视界

通过交互模型、图解和动画学习化学的非商业学习工具。从认识元素到探索分子、反应与工业过程，不只是查资料，而是带着问题动手探索。

## 从基础到应用的学习路径

| 知识章节 | 内容 |
| --- | --- |
| 01 物质与原子 | 粒子图中的物质分类，原子、元素与周期表 · 2 课 |
| 02 分子与化学键 | 电子转移与共用，结构式与立体分子模型 · 2 课 |
| 03 元素及化合物 | 钠、氯、铁、氮、硫等典型物质的性质与转化 · 7 课 |
| 04 反应与平衡 | 反应速率的控制变量，动态平衡 · 2 课 |
| 05 溶液与离子 | 导电、电离、盐类水解与滴定 · 3 课 |
| 06 化学与电能 | 原电池、电解池、金属腐蚀与防护 · 3 课 |
| 07 工业与生活 | 合成氨、炼铁、冶炼、制硫酸等综合应用 · 9 课 |

共 28 课：3 节原生基础交互课 + 25 门中文 3D 课件。实验是知识章节中的学习活动，不再与知识类别混排；学习路径提供先修建议，但不强制锁课。当前内容是入门衔接与高中专题探索，不宣称覆盖完整的初高中化学课程。

首页给出下一步建议，章节页展示学习目标和有序课程，目录可按章节、关键词与未完成状态筛选。元素周期表作为独立的随查工具，保留 118 种元素、原子模型、性质热力图、分类筛选与中英文查询。

每课统一采用 **课前理解 → 互动探索 → 检验理解**：先看目标和观察任务，再进入模型，最后用一道带解释的概念题检验理解。三维课件进入探索时才在 `sandbox="allow-scripts"` 的 iframe 中加载；切换本课页签保留当前实验，离开课程则卸载，不在后台运行。课程内保留原版分步引导、交互操作和课内考核。实验就绪状态来自运行时信号，不将 iframe 页面加载成功等同于实验成功。

页面使用统一尺寸规则、卡片比例和阅读宽度，没有拖动分栏控件。窄屏课件改为「场景 / 操作 / 讲解」三个视图，并用下拉框同步切换真实实验步骤；画布仍保持原运行时的完整视口尺寸，不破坏坐标拾取。模型边界说明在「讲解」面板中可展开。窄屏周期表按原子序数展示可读元素卡片，不以横向滚动换取完整表格；完整桌面周期表保留族与周期的位置。

原课件内的「目录」接入了本地化学课件目录：嵌入模式下选课会同步切换工作台，独立打开时则直接跳转对应课件，不依赖上游网站或不存在的页面。

学习记录只保存在当前浏览器的 localStorage，不上传服务器。「我的学习记录」分别展示打开课程、手动完成、概念题答对的数量，不把打开页面或手动完成等同于掌握。概念题保存最近一次答案并支持重答；课内考核分数不纳入此记录。保留对旧版本机记录的兼容。重新进入课程不恢复课内步骤、实验参数或分数。存储不可用时会显示提示，可继续学习但不持久保存记录。元素工具支持中英文切换，学习工作台与引入的课件为中文。

## 本地运行

需要 Node.js >= 18.18。

```shell
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

构建产物在 `dist`，可以部署到静态服务器，或使用现有 Dockerfile。Docker 镜像使用仓库中的 `nginx.conf`：开启 gzip，`assets/` 下带哈希的文件长期缓存，其余文件每次协商缓存；部署到其他服务器时建议同样开启压缩，单个课件页面约 1 MB。页面采用 hash 路由，无需额外的 SPA 服务端重写；相对资源地址兼容子路径部署。所有引入的课程、封面和 3D 运行代码已保存在本地，不依赖铜匠实验室在线站点。首次访问需要启动 HTTP 服务，不支持直接双击项目的 `index.html`；元素媒体与维基百科外链仍需要联网。

## 内容与代码结构

- `src/learning/`：学习工作台、课程分类、搜索与本机记录。
- `src/learning/curriculum.ts`：章节、有序课程、先修关系、目标、观察任务、概念题。
- `src/learning/native.ts`：物质分类、原子结构、化学键的原生交互模型。
- `src/data/lessons.json`：仅化学课程目录，保留教材位置和步骤信息。
- `src/modules/`：原元素周期表、原子模型、热力图等交互能力。
- `public/lessons/tongjiang/`：完整原版课件、封面及授权声明。
- `tests/`：元素工具和学习工作台的自动化测试。

从已核对的本地参考仓库重新导入化学资源：

```powershell
node .\scripts\import-lessons.mjs 'C:\path\to\tongjiang-lab'
```

导入脚本只接受已审阅的 25 门化学课程，不会引入物理、生物或地理课程。升级参考目录时，应重新审阅课程与授权，并同步分类及测试。

### 扩充课程

1. 在 `curriculum.ts` 的 `units` 中维护章节，在 `lessonPlan` 中按学习顺序添加课程。每课必须明确所属章节、知识点、难度、建议时长、先修、目标、观察任务、核心认识和概念题。
2. 先修引用使用已有课程的 slug，且必须出现在当前课程之前，避免缺失或循环依赖。新增课程会自动进入路径、章节、搜索和进度统计。
3. 引入模拟课需提供本地 HTML、封面及相应目录元数据，并重新审阅授权和隔离要求；原生模型则在 `native.ts` 中实现并扩展类型。不要直接修改第三方打包脚本。
4. 更新数量断言、校验全部资产及先修关系，并在真实浏览器检查交互、键盘与窄屏布局。
