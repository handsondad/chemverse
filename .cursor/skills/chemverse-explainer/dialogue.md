# 写问答

文章写在 `src/learning/stories/<slug>.ts`，导出一个 `Story`（类型见同目录 `types.ts`），登记在 `stories/index.ts`。`npm run story:new -- <slug>` 会把这两步做好。写完跑 `npm run story:check -- <slug>`，再跑 `npm run voice -- <slug>` 配音。

**对话会被读出来**：小念和爸爸的每一句都是配音稿，写成嘴上说得出的话。化学式、方程式放进 `eq`（不读），句子里用名字（「铁离子」而不是只写 Fe³⁺）；非要写符号，就在 `src/learning/voice.ts` 的 `speakable()` 里补上读法。

## 字段

| 字段 | 写什么 |
|---|---|
| `slug` | 和 `curriculum.ts` 里的课一致 |
| `title` | 小念口吻的问题，必须带「？」：「原子不是都小得看不见吗？为什么越往周期表的左下角原子越大？」 |
| `trigger` | 小念刚遇到的那件事，一句话、具体到场景：「小念在化学教室门口看见墙上挂着一张大表……」 |
| `dialogue` | 5–8 轮 `{ nian, dad, eq?, figure?, show? }` |
| `tip` | 给大人：安全须知、数字的出处或口径、教材差异、受了谁的启发；至少 20 字 |
| `film` | 可选，见 film.md |

每轮里：
- `eq`：这一轮的化学方程式，单独排一行（`CaO + H₂O = Ca(OH)₂`），下标用 ₂₃ 这类字符。
- `figure`：爸爸边说边指的一张图，见 figures.md。
- `show`：`{ kind: 'lab', step, label }` 跳到实验台第 `step` 段（3D 课件的第几步，或 `cards` 的下标，从 0 数）；或 `{ kind: 'steps', frames }` 一排 2–4 格的小图解（emoji + ≤8 字）。

## 检查器会拦的

- 5–8 轮；标题带「？」；`trigger` 一句话。
- 除最后一轮外，小念每句都带「？」。
- 从第 2 轮起，小念的问题要用上爸爸上一句里的一个有意义的两字词（「石灰」「氢气」「压强」；「什么」「这个」这种不算）。检查器取的是相邻两个汉字，两个字里只要有一个是「的了吗是我你这那就也都还在有和么什怎为个一不没会要说想看能可以得很太好真再」这类虚字就不算；最稳的办法是让小念原样复述爸爸刚说的一个名词：「多出来的电子能跑，石墨才导电？」。
- 最后一轮小念以「我懂了」或「我明白了」开头。
- 爸爸每句 20–180 字；`tip` 至少 20 字。
- `show.lab.step` 要在实验台的段数范围内。
- 配图和动画的规矩见 figures.md、film.md。

## 写好的标准（检查器管不到的）

**小念**：孩子的口气，短句，带情绪：「哇，它在水面上乱跑！」。追问顺着爸爸刚说的新词往下挖，不跳题：爸爸说了「电子层」，小念就问「电子层满了是什么样子？」。

**爸爸**：
- 第一句就给答案，再解释。
- 一个比方只讲一件事，用孩子见过的东西：住址簿、洋葱皮、拔河、楼梯、磁铁、找零钱。比方有漏洞就说一句「别全信这个比方」。
- 比方说完说真名，只说一次：「……这叫电负性。」后面就直接用。
- 数字要真实、可查；图里和动画里出现的数字只能是爸爸说过的。不确定就直说。
- 常见误会点名说破：「很多人以为……，其实……」。
- 不堆考纲术语：「活化分子百分数」「电子云重叠」这类话换成孩子的说法，真要用就先打比方。

**追问链的常见顺序**（不必每次全用）：
1. 现象是怎么回事（是什么）
2. 一步步怎么发生（粒子在干什么）
3. 为什么非得这样，不这样会怎样
4. 常见误会或特例
5. 生活里能用来做什么 / 我能做什么
6. 小念总结，爸爸肯定并给一个好习惯

## 例子（节选自 `atom-size-trend.ts`）

```ts
{
  nian: '爸爸，原子不是都小得看不见吗？怎么还分大个子和小个子？',
  dad: '再小也有大小之分。原子的大小主要看电子在核外铺得有多开：最小的氦半径约 31 皮米，大个子铯约 298 皮米，差了快 10 倍。……',
  figure: { kind: 'table', paint: 'radius', caption: '原子半径地图：颜色越暖原子越大……', link: { mode: 'radius', label: '在周期表里切到「半径」' } },
},
{
  nian: '为什么大个子都挤在左下角？往下走为什么会变大？',
  dad: '往下走一行，原子就多住一层电子。就像洋葱多包了一层皮，个头自然大一圈。……',
  figure: { kind: 'sizes', caption: '第 1 族从上往下：电子层每多一层，原子就大一圈。', atoms: [3, 11, 19, 37, 55] },
},
// ……往右反而变小（误会）→ 两股力量 → 大小和爱不爱丢电子 ……
{
  nian: '我懂了！往下多一层电子，原子变大；往右层数不变但核电荷变大，原子被拉小。……',
  dad: '总结得真清楚！下次看到周期表，先在心里画两个箭头：往下变大、往右变小。……',
},
```

第 2 轮的「左下角」接的是爸爸上一句的原话，这就是追问链。

## 全新的题（没有课件）

先在 `curriculum.ts` 的 `lessonPlan` 里写一条形态 A（字段见 AGENTS.md 第 3 节）：`cards` 写 3–5 张，按「现象 → 微观 → 方程式」各说一段，它们既是 `story:new` 的草稿素材，也是 `show.lab.step` 数的段数。`hook` 用「生活中的化学 · 」开头的一个悬念句；`check` 三个选项、只有一个对。`prerequisites` 里的课必须排在它前面，新条目一般就插在同主题最后一篇的后面。然后 `story:new` 生成草稿，再按下面改写。

## 草稿怎么改

`story:new` 预填的是课件自动装配的问答：内容对，但口气是教材的（「教材只给了用品和一张空表……」）。改写时：
- 删掉「教材」「本课」「实验台上」这类老师口吻，换成小念生活里的场景；
- 并掉重复的轮次，控制在 5–8 轮；
- 保留方程式和 `show.lab` 跳转（它们和 3D 课件的步骤对得上），删掉用不上的；
- 每轮补上 `figure`，把注释掉的 `// figure:` 行换成真的图。
