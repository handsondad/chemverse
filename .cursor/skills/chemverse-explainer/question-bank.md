# 化学奇遇记 · 题库

每一题都是一篇「小念 × 爸爸」文章的种子。已经写成文章的 60 题不在这里重复列，用 `npm run story:todo` 看（按 8 个主题列出）。下面是**候选**：只记了线索，写之前必须照 [sources.md](sources.md) 重新查证，查不实就换题。新想到的题按同样的列加进对应主题的表里。

## 选题标准

- **从生活出发**：厨房、浴室、玩具、节日、出门，小念真会碰到的一幕。
- **破一个误会**：每题瞄准一个常见的错误想法（「烧掉就没了」「铜不会生锈」），在文章里点名说破，有动画时用 `myth` 卡划掉。
- **对得上课本**：入门 ≈ 初中，进阶 ≈ 高中必修，综合 ≈ 高中选择性必修 / 工业流程。
- **不重复**：先 `npm run story:todo` 看同主题已有的题，一个题只回答一个「为什么」。
